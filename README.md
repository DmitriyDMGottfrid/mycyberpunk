## 📖 О проекте

**MY CYBERPUNK** — это полноценный движок для сайта в эстетике киберпанк. Сделан на чистом Node.js + Express, без фреймворков и сборщиков. 

Изначально создавался как личный сайт-портфолио с блогом, но вырос в универсальную платформу: тут есть система ролей, авто-модерация, магазин, галерея, книги, ресурсы и даже встроенный AI-ассистент на DeepSeek, который читает код твоего сайта и помогает с ним работать.

**Подходит для:**
- 🎨 Личного сайта-портфолио в стиле cyberpunk
- 📰 Блога с комментариями и модерацией
- 🎮 Геймдев-портала с новостями и галереей
- 📚 Библиотеки с книгами и мерчем
- 🚀 Любого проекта, где нужен «не такой как у всех» дизайн

## ✨ Возможности

### 🎭 Публичная часть

| Раздел | URL | Описание |
|---|---|---|
| **Центральный хаб** | `/hub` | Главная страница с новостями и таймлайном |
| **Поток данных** | `/stream` | Лента новостей |
| **Когнитивный фид** | `/cog` | Блог с постами, комментариями, rich-editor |
| **Матрица образов** | `/matrix` | Галерея с альбомами, фото и видео |
| **Архив логов** | `/logs` | Библиотека книг |
| **Риппердок** | `/ripper` | Каталог имплантатов и мерча |
| **Имплантаты** | `/implant` | Каталог внешних ресурсов |
| **Манифест** | `/manifest` | О проекте |
| **Доступ** | `/access` | Регистрация и вход |
| **Личный кабинет** | `/profile` | Профиль пользователя, заказы, комментарии |
| **Публичный профиль** | `/user/:username` | Профиль для других пользователей |

### 🔐 Админ-панель (`/admin`)

- **Dashboard** — статистика по всем разделам
- **Посты** — блог с модерацией
- **Новости** — лента событий
- **Книги** — библиотека с загрузкой файлов
- **Галерея** — альбомы, фото, видео
- **Ресурсы** — каталог ссылок
- **Мерч и заказы** — магазин
- **Пользователи** — управление ролями, блокировки, сброс пароля
- **Комментарии** — модерация с фильтрами
- **Стоп-слова** — авто-модерация комментариев
- **AI-Ассистент** — встроенный чат с DeepSeek
- **Настройки** — общие, SEO, соцсети, страницы, доп. страницы, система, бэкапы
- **Уровни доступа** — настройка ролей на публичной странице
- **Мой профиль** — смена логина, email, пароля

### ⚙️ Технические фичи

- 🎨 **Киберпанк-стиль** — CRT-эффекты, глитчи, звуки, анимации
- 🔐 **JWT-аутентификация** с 5 уровнями доступа (guest → admin)
- 🛡️ **Авто-модерация** комментариев по стоп-словам
- 🖼️ **Загрузка изображений** — аватары, обложки, посты, мерч, галерея
- 📝 **Rich-text editor** для постов и комментариев
- 🤖 **AI-ассистент** на DeepSeek с доступом к файлам проекта
- 🎨 **Кастомизация страниц** — название, шрифт, hero-картинка, HTML в `<head>`
- 📄 **Дополнительные страницы** — как дочерние с группировкой по категориям
- 💾 **Бэкап БД** — экспорт/импорт через админку
- 🔍 **Глобальный поиск** по админке
- 📱 **Адаптивная вёрстка**

## 🛠️ Технологии

**Backend:**
- Node.js 18+
- Express.js — веб-сервер
- sql.js — SQLite в чистом JS (не требует нативной сборки)
- bcryptjs — хеширование паролей
- jsonwebtoken — JWT-токены
- multer — загрузка файлов
- dotenv — переменные окружения

**Frontend:**
- Чистый HTML5 + CSS3 + JavaScript (ES6+)
- Web Audio API — звуковые эффекты
- CSS-анимации, clip-path, glitch-эффекты

**Инфраструктура:**
- Nginx — reverse-proxy + HTTPS
- PM2 — менеджер процессов
- Let's Encrypt / Certbot — SSL-сертификаты
- UFW — firewall
- Cloudflare — DNS и защита

## 🚀 Быстрый старт

### Требования

- Node.js 18 или выше
- npm или yarn

### Установка

```bash
# 1. Клонируй репозиторий
git clone https://github.com/твой-логин/cyberpunk-engine.git
cd cyberpunk-engine

# 2. Установи зависимости
npm install

# 3. Создай файл .env (см. .env.example)
cp .env.example .env
nano .env  # заполни своими значениями

# 4. Запусти
node server.js
